# Casa Oliva — demo de restaurante

Demo ficticia de restaurante mediterráneo creada como plantilla sectorial para Nébula Digital Studio. Identidad cálida en crema, oliva y terracota, con carta por categorías y solicitud de reserva.

## Personalización rápida

Edita `src/data/siteData.ts` para cambiar marca, textos, platos, precios, imágenes, teléfono, dirección, horario y reseñas. Los datos de ubicación, contacto y opiniones incluidos son de ejemplo; sustitúyelos por información verificada antes de usar la plantilla con un restaurante real.

## Desarrollo

```bash
npm install
npm run dev
```

## Producción

```bash
npm run build
npm run start
```
